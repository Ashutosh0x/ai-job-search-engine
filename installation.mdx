## Quick Installation

### 1. Clone the Repository

```bash
git clone https://github.com/jobspark-ai/jobspark.git
cd jobspark
```

### 2. Install Dependencies

```bash
npm install
# or
yarn install
```

### 3. Environment Setup

Create a `.env.local` file in the root directory:

```bash
cp .env.example .env.local
```

Fill in your environment variables:

```env
# Supabase Configuration
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key

# Google AI Configuration
GOOGLE_AI_API_KEY=your_google_ai_key

# Email Configuration (Resend)
RESEND_API_KEY=your_resend_api_key

# Stripe Configuration
STRIPE_SECRET_KEY=sk_test_your_stripe_secret_key
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_test_your_stripe_publishable_key
STRIPE_WEBHOOK_SECRET=whsec_your_webhook_secret

# Stripe Price IDs (create under each Product → Prices)
STRIPE_BASIC_PRICE_ID=price_basic_plan_id
STRIPE_PRO_PRICE_ID=price_pro_plan_id
STRIPE_PREMIUM_PRICE_ID=price_premium_plan_id

# Application Configuration
NEXT_PUBLIC_APP_URL=http://localhost:3000
NEXTAUTH_SECRET=your_nextauth_secret
NEXTAUTH_URL=http://localhost:3000
```

### 4. Database Setup

<Steps>
  <Step title="Install Supabase CLI">
    ```bash
    npm install -g supabase
    ```
  </Step>
  <Step title="Login to Supabase">
    ```bash
    supabase login
    ```
  </Step>
  <Step title="Initialize Project">
    ```bash
    supabase init
    ```
  </Step>
  <Step title="Start Local Development">
    ```bash
    supabase start
    ```
  </Step>
</Steps>

### 5. Run Database Migrations

```bash
npm run db:migrate
# or
supabase db reset
```

### 6. Start Development Server

```bash
npm run dev
# or
yarn dev
```

Your application will be available at [http://localhost:3000](http://localhost:3000)

## Production Deployment

### Vercel Deployment

<Steps>
  <Step title="Connect Repository">
    Connect your GitHub repository to Vercel
  </Step>
  <Step title="Configure Environment">
    Add all environment variables in Vercel dashboard
  </Step>
  <Step title="Deploy">
    Vercel will automatically deploy on push to main branch
  </Step>
  <Step title="Custom Domain">
    Configure your custom domain in Vercel settings
  </Step>
</Steps>

### Docker Deployment

<CardGroup cols={2}>
  <Card title="Dockerfile">
    ```dockerfile
    FROM node:18-alpine
    WORKDIR /app
    COPY package*.json ./
    RUN npm ci --only=production
    COPY . .
    RUN npm run build
    EXPOSE 3000
    CMD ["npm", "start"]
    ```
  </Card>
  <Card title="Docker Compose">
    ```yaml
    version: '3.8'
    services:
      app:
        build: .
        ports:
          - "3000:3000"
        environment:
          - NODE_ENV=production
    ```
  </Card>
</CardGroup>

## Troubleshooting

### Common Issues

<CardGroup cols={2}>
  <Card title="Build Errors">
    - Check Node.js version (18+)
    - Clear npm cache: `npm cache clean --force`
    - Delete node_modules and reinstall
    - Check for TypeScript errors
  </Card>
  <Card title="Database Issues">
    - Verify Supabase connection
    - Check environment variables
    - Run migrations: `npm run db:migrate`
    - Reset database if needed

## Security Considerations

### Environment Security

<CardGroup cols={2}>
  <Card title="API Keys">
    - Never commit API keys to version control
    - Use environment variables
    - Rotate keys regularly
    - Use least privilege principle
  </Card>
  <Card title="Database Security">
    - Enable Row Level Security (RLS)
    - Use prepared statements
    - Implement proper authentication
    - Regular security audits
  </Card>
</CardGroup>

### Production Security

<CardGroup cols={2}>
