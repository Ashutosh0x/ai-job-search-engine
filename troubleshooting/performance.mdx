# Performance

Improve app performance and responsiveness.

## Quick Checks
- Stable internet connection
- Latest browser version
- Disable heavy extensions

## App Tips
- Reduce simultaneous uploads
- Limit large resume files
- Close unused tabs

## Report
- Include steps, timestamps, and console/network logs when contacting support
