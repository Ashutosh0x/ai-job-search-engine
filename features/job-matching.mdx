# AI Job Matching

JobSpark AI's intelligent job matching system uses advanced machine learning algorithms to connect you with the most relevant job opportunities based on your skills, experience, and preferences.

## Overview

Our AI Job Matching system analyzes multiple factors to provide personalized job recommendations:

- **Skill Alignment** - Matches your technical and soft skills with job requirements
- **Experience Level** - Considers your years of experience and career progression
- **Location Preferences** - Factors in your preferred work location and remote preferences
- **Salary Expectations** - Aligns with your compensation requirements
- **Company Culture** - Matches your work style and values with company culture
- **Industry Focus** - Prioritizes opportunities in your preferred industries

## How It Works

## API Integration

### Job Matching Endpoint

```typescript
GET /api/jobs/matching
```

**Query Parameters:**
```json
{
  "userId": "user_id",
  "location": "San Francisco, CA",
  "salaryMin": 80000,
  "salaryMax": 150000,
  "remote": true,
  "experience": "mid",
  "skills": ["JavaScript", "React", "Node.js"]
}
```

**Response:**
```json
{
  "jobs": [
    {
      "id": "job_123",
      "title": "Senior Frontend Engineer",
      "company": "Tech Corp",
      "location": "San Francisco, CA",
      "salary": "$120,000 - $150,000",
      "matchScore": 92,
      "skills": ["JavaScript", "React", "TypeScript"],
      "description": "We're looking for a senior frontend engineer...",
      "postedDate": "2024-01-15",
      "applicationUrl": "https://techcorp.com/careers"
    }
  ],
  "totalCount": 45,
  "filters": {
    "applied": ["job_456"],
    "saved": ["job_789"]
  }
}
```
