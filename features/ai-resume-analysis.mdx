# AI Resume Analysis

JobSpark AI's intelligent resume analysis feature uses advanced machine learning algorithms to provide comprehensive feedback on your resume, helping you optimize it for better job opportunities.

## Overview

Our AI Resume Analysis system evaluates your resume across multiple dimensions:

- **ATS Compatibility** - Ensures your resume passes Applicant Tracking Systems
- **Skill Gap Analysis** - Identifies missing skills for your target roles
- **Content Optimization** - Suggests improvements for clarity and impact
- **Keyword Analysis** - Recommends relevant keywords for your industry
- **Format Assessment** - Evaluates layout and formatting effectiveness

## API Integration

### Resume Analysis Endpoint

```typescript
POST /api/analyze-resume
```

**Request Body:**
```json
{
  "file": "base64_encoded_resume",
  "fileType": "pdf|docx",
  "targetRole": "Software Engineer",
  "industry": "Technology"
}
```

**Response:**
```json
{
  "analysis": {
    "atsScore": 85,
    "skillGaps": ["React", "AWS"],
    "suggestions": [
      "Add quantifiable achievements",
      "Include more action verbs"
    ],
    "keywordAnalysis": {
      "missing": ["JavaScript", "API"],
      "overused": ["responsible for"]
    }
  }
}
```

### Resume Parsing Endpoint

```typescript
POST /api/parse-resume
```

Extracts structured data from your resume:

```json
{
  "parsedData": {
    "personalInfo": {
      "name": "John Doe",
      "email": "john@example.com",
      "phone": "+1-555-0123"
    },
    "experience": [
      {
        "title": "Software Engineer",
        "company": "Tech Corp",
        "duration": "2020-2023",
        "achievements": ["Led team of 5 developers"]
      }
    ],
    "education": [...],
    "skills": ["JavaScript", "React", "Node.js"]
  }
}
```

## Troubleshooting

### Common Issues

  <Card title="File Upload Problems">

    - Clear browser cache
    - Try different browser

### Performance Tips

- **File Size**: Keep resumes under 5MB for faster processing
- **Format**: Use PDF for best compatibility
- **Content**: Ensure text is selectable (not image-based)
- **Timing**: Avoid peak usage hours for faster results
