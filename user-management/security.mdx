# Security

Keep your account safe with modern controls.

## Two-Factor Authentication (2FA)
- Enable via authenticator app, SMS, or security key
- Store backup codes securely

## Sessions & Devices
- View active sessions
- Sign out from other devices

## Alerts
- Login notifications
- Suspicious activity alerts

## Best Practices
- Use a unique, strong password
- Enable 2FA
- Review recent logins regularly
