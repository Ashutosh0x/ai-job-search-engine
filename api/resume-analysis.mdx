# Resume Analysis API

AI-powered resume analysis and optimization through our RESTful API endpoints.

## Overview

Our Resume Analysis API provides intelligent analysis of resumes, offering insights on ATS optimization, skill gaps, content quality, and improvement recommendations.

## Base URL

```
https://api.jobspark.ai/v1
```

## Authentication

All API requests require authentication. Include your API key in the Authorization header:

```bash
Authorization: Bearer YOUR_API_KEY
```

## Endpoints

### Analyze Resume

Analyze a resume and get comprehensive insights.

```bash
POST /api/analyze-resume
```

**Request Body:**
```json
{
  "resume": "base64_encoded_resume_content",
  "targetRole": "Software Engineer",
  "targetIndustry": "Technology",
  "analysisType": "comprehensive"
}
```

**Response:**
```json
{
  "analysis": {
    "atsScore": 85,
    "skillGaps": [
      {
        "skill": "React.js",
        "importance": "high",
        "suggestion": "Add React.js experience to your resume"
      }
    ],
    "contentQuality": {
      "score": 78,
      "suggestions": [
        "Quantify achievements with specific metrics",
        "Use more action verbs in descriptions"
      ]
    },
    "keywordOptimization": {
      "matchedKeywords": ["JavaScript", "Python", "AWS"],
      "missingKeywords": ["Docker", "Kubernetes"],
      "suggestions": ["Add containerization technologies"]
    }
  },
  "recommendations": [
    "Add quantifiable achievements",
    "Include more technical skills",
    "Optimize for ATS systems"
  ]
}
```

### Parse Resume

Extract structured data from resume content.

```bash
POST /api/parse-resume
```

**Request Body:**
```json
{
  "resume": "base64_encoded_resume_content",
  "format": "pdf"
}
```

**Response:**
```json
{
  "parsedData": {
    "personalInfo": {
      "name": "John Doe",
      "email": "john@example.com",
      "phone": "+1-555-0123",
      "location": "San Francisco, CA"
    },
    "experience": [
      {
        "company": "Tech Corp",
        "title": "Senior Developer",
        "duration": "2020-2023",
        "description": "Led development team..."
      }
    ],
    "education": [
      {
        "institution": "University of Technology",
        "degree": "Bachelor of Science",
        "field": "Computer Science",
        "graduationYear": "2020"
      }
    ],
    "skills": ["JavaScript", "Python", "React", "Node.js"]
  }
}
```

### Upload Resume

Upload a resume file for analysis.

```bash
POST /api/upload-resume
```

**Request Body (multipart/form-data):**
```
file: resume.pdf
metadata: {
  "userId": "user123",
  "analysisType": "comprehensive"
}
```

**Response:**
```json
{
  "uploadId": "upload_abc123",
  "status": "uploaded",
  "analysisUrl": "/api/analyze-resume/upload_abc123"
}
```

## Error Handling

### Common Error Codes

| Status Code | Error Type | Description |
|-------------|------------|-------------|
| `400` | Bad Request | Invalid request format or missing parameters |
| `401` | Unauthorized | Invalid or missing API key |
| `413` | Payload Too Large | Resume file exceeds size limit |
| `422` | Unprocessable Entity | Unsupported file format |
| `429` | Too Many Requests | Rate limit exceeded |
| `500` | Internal Server Error | Server processing error |

### Error Response Format

```json
{
  "error": {
    "code": "INVALID_FILE_FORMAT",
    "message": "Unsupported file format. Please upload PDF, DOC, or DOCX files.",
    "details": {
      "supportedFormats": ["pdf", "doc", "docx"],
      "fileSize": "10MB maximum"
    }
  }
}
```

## Integration Examples

### JavaScript/Node.js

```javascript
const analyzeResume = async (resumeFile) => {
  const formData = new FormData();
  formData.append('file', resumeFile);
  
  const response = await fetch('https://api.jobspark.ai/v1/upload-resume', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${API_KEY}`
    },
    body: formData
  });
  
  return response.json();
};
```

### Python

```python
import requests

def analyze_resume(file_path, api_key):
    url = "https://api.jobspark.ai/v1/upload-resume"
    
    with open(file_path, 'rb') as file:
        files = {'file': file}
        headers = {'Authorization': f'Bearer {api_key}'}
        
        response = requests.post(url, files=files, headers=headers)
        return response.json()
```

### cURL

```bash
curl -X POST https://api.jobspark.ai/v1/upload-resume \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "file=@resume.pdf" \
  -F "metadata={\"userId\":\"user123\"}"
```

## Best Practices

### File Preparation

1. **Use PDF format** for best compatibility
2. **Keep file size under 5MB** for faster processing
3. **Ensure text is selectable** (not image-based)
4. **Use standard fonts** (Arial, Calibri, Times New Roman)

### API Usage

1. **Implement retry logic** for failed requests
2. **Handle rate limits** gracefully
3. **Cache results** when appropriate
4. **Validate responses** before processing

### Error Handling

1. **Check status codes** before processing responses
2. **Implement exponential backoff** for retries
3. **Log errors** for debugging
4. **Provide user-friendly error messages**
