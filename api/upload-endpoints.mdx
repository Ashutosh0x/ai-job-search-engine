# Upload Endpoints

Secure file upload and document management through our RESTful API endpoints.

## Overview

Our Upload API provides secure, scalable file upload capabilities for resumes, cover letters, portfolios, and other job search documents with automatic processing and optimization.

## Base URL

```
https://api.jobspark.ai/v1
```

## Authentication

All API requests require authentication. Include your API key in the Authorization header:

```bash
Authorization: Bearer YOUR_API_KEY
```

## Endpoints

### Upload Resume

Upload a resume file for processing and analysis.

```bash
POST /api/upload/resume
```

**Request Body (multipart/form-data):**
```
file: resume.pdf
metadata: {
  "userId": "user123",
  "version": "v2.1",
  "targetRole": "Software Engineer",
  "analysisType": "comprehensive"
}
```

**Response:**
```json
{
  "uploadId": "upload_abc123",
  "filename": "resume.pdf",
  "fileSize": 245760,
  "contentType": "application/pdf",
  "status": "uploaded",
  "processingStatus": "processing",
  "analysisUrl": "/api/analyze-resume/upload_abc123",
  "downloadUrl": "/api/download/upload_abc123",
  "expiresAt": "2024-02-15T10:30:00Z"
}
```

## Error Handling

### Common Error Codes

| Status Code | Error Type | Description |
|-------------|------------|-------------|
| `400` | Bad Request | Invalid file format or metadata |
| `401` | Unauthorized | Invalid or missing API key |
| `413` | Payload Too Large | File exceeds size limit |
| `415` | Unsupported Media Type | Unsupported file format |
| `429` | Too Many Requests | Rate limit exceeded |
| `500` | Internal Server Error | Server processing error |

### Error Response Format

```json
{
  "error": {
    "code": "FILE_TOO_LARGE",
    "message": "File size exceeds maximum limit of 10MB",
    "details": {
      "fileSize": 15728640,
      "maxSize": 10485760,
      "supportedFormats": ["pdf", "doc", "docx"]
    }
  }
}
```

## Integration Examples

### JavaScript/Node.js

```javascript
const uploadResume = async (file, metadata) => {
  const formData = new FormData();
  formData.append('file', file);
  formData.append('metadata', JSON.stringify(metadata));
  
  const response = await fetch('https://api.jobspark.ai/v1/upload/resume', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${API_KEY}`
    },
    body: formData
  });
  
  return response.json();
};
```

### Python

```python
import requests

def upload_resume(file_path, metadata, api_key):
    url = "https://api.jobspark.ai/v1/upload/resume"
    
    with open(file_path, 'rb') as file:
        files = {'file': file}
        data = {'metadata': json.dumps(metadata)}
        headers = {'Authorization': f'Bearer {api_key}'}
        
        response = requests.post(url, files=files, data=data, headers=headers)
        return response.json()
```

### cURL

```bash
curl -X POST https://api.jobspark.ai/v1/upload/resume \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "file=@resume.pdf" \
  -F "metadata={\"userId\":\"user123\",\"version\":\"v2.1\"}"
```

## Best Practices

### File Preparation

1. **Use PDF format** for resumes and cover letters
2. **Keep file sizes reasonable** for faster uploads
3. **Validate content** before uploading
4. **Use descriptive filenames** for better organization

### Upload Strategy

1. **Implement retry logic** for failed uploads
2. **Handle rate limits** gracefully
3. **Validate responses** before processing
4. **Monitor upload progress** for large files

### Security Considerations

1. **Validate file types** on client side
2. **Check file sizes** before upload
3. **Sanitize metadata** to prevent injection
4. **Use secure connections** (HTTPS only)
