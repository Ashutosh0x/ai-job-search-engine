# Job Search Strategy

A repeatable system for landing interviews faster.

## Weekly Plan
- Identify 10–15 target roles
- Tailor resume with keywords
- Apply with a focused cover letter
- Track follow‑ups and outcomes

## Use Analytics
- Review conversion from application → interview → offer
- Double down on channels with highest conversion

## Improve Signal
- Showcase quantified impact
- Align skills with job description
- Ask for referrals
