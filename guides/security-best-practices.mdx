# Security Best Practices

Protect your account and data.

## Account
- Strong, unique passwords
- Enable 2FA
- Review active sessions periodically

## Data
- Export and backup periodically
- Manage third‑party connections
- Limit sharing of personal data

## Device
- Keep OS and browser updated
- Use reputable password manager
